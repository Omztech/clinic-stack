Day 1: WSL, Docker, Git, VS Code set up. Docker runs inside Linux, no Docker Desktop.
Level 0: ssh logs into another computer. ls shows files. cat shows what is inside a file.
Level 1: a file called - confuses Linux. ./- means the file in this folder.
Level 2: spaces split a command into pieces. Quotes keep a name together. ./ stops a name with dashes being read as an option.
Level 3: cd moves into a folder. Files starting with a dot are hidden. ls -a shows them, like .git and .env
